Honest caveats

  1. Recognizability is saturated. On the flat portraits every valid config sits ~1.04, all within seed noise. No config makes the SHADOW meaningfully better — the win is crypticness + reliability, not shadow quality.
  2. The winner still fails the gate 1/6 seeds (marginally, ~84.6%). For a single physical build you'd generate a few seeds and pick a passing one — legitimate — but it is not gate-proof on every seed.
  3. Crypticness is image-dependent — strong on the detailed portraits (0.40), weak on simple bold images (0.58). Not a fixed property of the config.
  4. More shards do not help completeness — a genuinely useful finding: the binding limit is panel PLACEMENT reaching the dark regions, fixed by raising K, not by adding material.
