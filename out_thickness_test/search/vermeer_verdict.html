Honest caveats

  1. Recognizability is low (~0.42) and unimprovable for these photographic sources — soft composition, not faces.
  2. Carry is seed-unstable — one seed spikes to ~0.6-0.9 across all configs. K=48 is more stable (0.411±0.075) than K=32 (0.347±0.123); pick K=48 if you value consistency over peak crypticness.
  3. Winner fails the gate on 1/6 seeds (K=48 fixes to 6/6). For one physical build, pick a passing seed.
  4. Reliability came from better search (K), not more shards — the recurring, useful finding.
